# CommitGuard web dashboard (placeholder)

Nothing is implemented here. The dashboard is **Phase 6** on the roadmap.

Planned views:

- Repositories and their security status
- Blocked commits and findings (with evidence and remediation)
- Policies and rules
- Audit history
- GitHub integrations

It will consume a future FastAPI layer over the audit store; no frontend
framework has been chosen, and no dependencies are added until work starts.
