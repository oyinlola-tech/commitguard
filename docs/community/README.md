# Community

CommitGuard is a public, MIT-licensed project maintained by one person. These
pages describe how to take part and what happens to what you send.

| Page | For |
|---|---|
| [external-evaluation.md](external-evaluation.md) | Evaluating CommitGuard and reporting what you found |
| [feedback-triage.md](feedback-triage.md) | What happens to an issue after you open it |
| [pilot-program.md](pilot-program.md) | Running CommitGuard on a real team's repositories |
| [case-study-template.md](case-study-template.md) | Writing up a real deployment |
| [data-policy.md](data-policy.md) | What is collected (very little) and what is not |
| [good-first-issues.md](good-first-issues.md) | Scoped work for a first contribution |

Contributing code: [CONTRIBUTING.md](../../CONTRIBUTING.md). Reporting a
vulnerability: [SECURITY.md](../../SECURITY.md) - privately, not in an issue.

No external evaluations have been recorded yet. No external production
