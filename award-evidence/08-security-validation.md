# 08 - Security validation

**TESTED / OBSERVED.** 13 recorded experiments, 350 security tests, 7,476
property-based examples per run. Evidence: `evidence/security/experiments.jsonl`,
regenerated by `commitguard reproduce security`.

## Outcomes

| Outcome | Count | Meaning |
|---|---|---|
| `prevented` | 8 | the attack did not achieve its goal at this layer |
| `detected` | 5 | it succeeded locally, and a later layer caught it |
| `bypassed` | 0 | (a documented local bypass appears as `detected` because the server-side layer catches it) |

## Server-side attacks

| Attack | Observed |
|---|---|
| Webhook signed with the wrong secret / altered after signing / unsigned | **HTTP 401** each; a correctly signed control accepted; 0 scans, 0 check runs |
| Delivery replayed, and an old event re-sent after a newer scan | `duplicate`; the newest commit's check remains **failure** |
| Stale re-run of an outdated commit's passing check | `ignored`; failing check remains current |
| Merge queue: a clean pull request queued behind an AI-attributed change | merge group check **failure** |
| Pull request disables / allows / deletes the policy | check exit 1 in all three cases |
| Repository configuration versus a mandatory policy | success without the floor, **failure** with it |
| GitHub API unreachable | job **error (infrastructure)**, no check conclusion |
| Installation permissions revoked | job **error (authorization)**, 0 check runs |
| Database failure during a webhook | **HTTP 500**, 0 scans, redelivery processed after recovery |
| Installation suspended | audit entry + critical notification, 0 scans |

**No path produces a passing check without a completed evaluation.**

## Adversarial input

- **Property-based fuzzing** of every parser that touches untrusted data: trailers,
  identities, configuration, YAML, webhook payloads and headers, API parameters,
  output encoders and redaction. It found **two detection bypasses** that
  hand-written cases missed.
- **ReDoS**: every regular expression in the source, found automatically, timed
  against 70 adversarial inputs. It found **two quadratic patterns** reachable
  from untrusted text, both rewritten as linear scans and verified equivalent over
  300,000 random strings.
- **Invariants over generated inputs**: determinism, order-independence,
  fail-closed behaviour, and the mandatory-policy floor.

## What is not proven

Branch protection is **modelled**, not exercised against github.com; the
server-side experiments run against a fake GitHub implementing the API surface
used. No independent security review has taken place - the orientation document
for one exists at [docs/security/review-guide.md](../docs/security/review-guide.md).
