# Security evidence

Generated by the test suites, not written by hand:

```bash
commitguard reproduce security --evidence-dir evidence/security
```

| File | Contains |
|---|---|
| `experiments.jsonl` | One line per security experiment: expected, observed, consequence, mitigation, limitation, outcome |
| `fuzzing.json` | Property-based example counts per property |
| `redos.json` | Worst-case timing for every regular expression, against adversarial input |

Recorded 2026-09-17: 13 experiments (8 prevented, 5 detected), 7,476 fuzzing
examples across 25 properties, 33 regular expressions measured with a worst case
of 133.9 ms against a 500 ms budget.

The narrative versions: [docs/research/](../../docs/research/) and
`reports/security-report.md`.
