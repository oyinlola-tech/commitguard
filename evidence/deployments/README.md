# Deployments

**Empty: no external production deployments have been recorded yet.**

If you deploy CommitGuard and are willing to say so, a record here holds only what
you choose to disclose:

| Field | Example |
|---|---|
| Project | a name, or "a UK fintech, name withheld" |
| Deployment type | local hooks / GitHub Actions / GitHub App |
| CommitGuard version | commit SHA |
| Platform | GitHub.com, Linux host |
| Date | when it started |
| Status | pilot, production, discontinued |

Private repository names and organization details are never published by default.
Nothing appears here without explicit permission, and it can be removed on request.

The pilot process: [docs/community/pilot-program.md](../../docs/community/pilot-program.md).
