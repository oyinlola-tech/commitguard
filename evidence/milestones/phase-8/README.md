# Phase 8: Organization governance

**Completed:** 2026-09-17

## Objective

Govern policy across many repositories without breaking everyone at once.

## Implementation

Repository groups, policy inheritance and effective-policy provenance, drafts and simulation against recorded scans, approval with separation of duties, staged rollouts, scoped expiring exceptions, security posture as explicit states, compliance reports, bulk operations and scheduled scans.

## Evidence

docs/organization-governance.md and seven companion pages

## Tests

Governance workflow, isolation, performance and dashboard tests.

## Results

A mandatory floor repositories cannot lower; every change versioned, approved and audited.

## Limitations

Experimental; no organization has used it.
