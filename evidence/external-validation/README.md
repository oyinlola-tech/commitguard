# External validation

**Empty: no external evaluations have been recorded yet.**

This is the most valuable evidence the project does not have. An evaluation is
someone who is not the author installing CommitGuard, using it, and writing down
what happened - including what did not work.

Each evaluation is recorded as `evaluation-00N.md` with:

| Field | |
|---|---|
| Scope | what was evaluated |
| Environment | OS, Git, Python, CommitGuard version, install method |
| Tasks performed | what they actually did |
| Issues discovered | with links to the issues raised |
| Feedback | in the evaluator's words, quoted with permission |
| Result | what worked, what did not |
| Permission | what the evaluator agreed to publish, and how to be credited |

`aggregate-results.md` will summarise them once more than one exists.

How to take part: [docs/community/external-evaluation.md](../../docs/community/external-evaluation.md).
